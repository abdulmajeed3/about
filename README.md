- 🏗️ **Full-stack delivery**: Python/FastAPI, Node.js, React, Next.js, TypeScript, ASP.NET Core, Angular
- ☁️ **Cloud, DevOps & data**: Azure, AWS, Docker, CI/CD, PostgreSQL, SQL Server, MongoDB, Supabase

8+ years across **healthcare, fintech, ERP and SaaS**: consulting, staff augmentation and end-to-end project delivery.
